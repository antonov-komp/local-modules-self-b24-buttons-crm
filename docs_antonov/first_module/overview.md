## Модуль «BP Button Field» (коробка Битрикс24)

Модуль «BP Button Field» расширяет стандартные возможности CRM Битрикс24 **только для коробочной версии продукта**.  
Он добавляет новый тип пользовательского поля — «Кнопка управления логикой» (`bp_button_field`), который позволяет запускать разные сценарии непосредственно из карточек CRM и смарт-процессов.

### Текущие action type

На baseline `28f73db` реализованы четыре режима:

1. `url` — открыть настроенный URL в `BX.SidePanel`.
2. `bp_launch` — запустить выбранный бизнес-процесс.
3. `bp_launch_with_params` — запросить строковое значение и передать его в параметр бизнес-процесса.
4. `bp_launch_with_button_params` — показать набор UI-кнопок, передать выбранное значение в параметр и запустить бизнес-процесс.

Модуль также содержит административный реестр настроек, ORM-таблицы настроек и логов, проверки прав, бизнес-логирование и поддержку CRM/смарт-процессов.

### Основные сценарии использования

- **Администратор CRM**:
  - создаёт пользовательское поле типа `bp_button_field` для нужной сущности;
  - выбирает тип действия;
  - настраивает URL либо шаблон бизнес-процесса и его параметры;
  - при необходимости задаёт варианты выбора и дополнительные параметры отображения.
- **Оператор/менеджер**:
  - видит в карточке CRM кнопку вместо обычного значения поля;
  - нажимает её;
  - получает SidePanel, запускает БП напрямую либо выбирает/вводит параметр перед запуском.

### Ограничения версии

- Целевая платформа: **1С-Битрикс24, коробочная редакция** (доступ к `/local/`, PHP и D7 ORM).
- Облачная версия Битрикс24 **не рассматривается** в рамках данного модуля.
- Все пути и примеры кода привязаны к `/local/modules/my.bpbutton/`.
